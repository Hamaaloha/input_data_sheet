## 測定評価シート データ入力アプリ（sheet_input_app.html）

スキャンした測定記録用紙（PDF・画像）を見ながら数値を入力するためのデスクトップ向けアプリ。

### 主な機能

- **PDF/画像の表示**：スキャンした記録シートを左ペインに表示しながら入力
- **OCR自動読み取り**：Tesseract.js を使用してスキャン画像から数値を自動認識
- **名前の一括入力**：Excelからコピペで氏名・学年・性別を一括入力
- **CSV/MD出力**：入力データをCSVまたはMarkdown形式でダウンロード

### 対応種目（6種目）

| 種目                     | 測定項目                  |
| ------------------------ | ------------------------- |
| 30m走                    | 10m・20m・30m（2試技）    |
| メディシンボール投げ     | 3試技（予備含む）         |
| CMJ                      | 跳躍高・滞空時間（2試技） |
| リバウンドジャンプ（RJ） | 跳躍高・RSI（2試技）      |
| 握力                     | 左右各2試技               |
| 背筋力                   | 2試技                     |

### 使い方

1. ブラウザで `sheet_input_app.html` を開く
2. 上部メニューで**種目**・**測定日**・**測定者**を設定
3. 「📂 スキャンを開く」でPDFまたは画像を読み込む
4. 「📋 名前を一括入力」でExcelから氏名をペーストするか、直接入力
5. 「🔍 OCRで数値読み取り」で数値を自動認識（結果を確認して適用）
6. 「📥 CSV」または「📄 MD」でデータをエクスポート

### OCR について

- [Tesseract.js v4](https://github.com/naptha/tesseract.js) をCDNから動的読み込み（初回は数秒かかる）
- **英語（数字）のみ**認識。日本語文字は無視されるため数値のみ抽出
- OCR結果はプレビューで確認してから適用可能（緑：正常、黄：要確認）

### 名前一括入力（Excelペースト）

Excelで氏名・学年・性別の列を選択してコピーし、ダイアログに貼り付けると自動的に3列に振り分けられます。

```
山田 太郎	4年	男
鈴木 花子	2年	女
```
