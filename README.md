# フィットネス測定アプリ集

スポーツ科学測定・評価ツール集。ブラウザのみで動作し、データは端末内で処理されます（外部サーバーへの送信なし）。

## アプリ一覧

| ファイル | 機能 |
|---|---|
| [index.html](index.html) | メニュー画面（全アプリへのリンク） |
| [sheet_input_app.html](sheet_input_app.html) | 測定評価シート データ入力（OCR対応） |
| [cmj_app.html](cmj_app.html) | CMJ（カウンタームーブメントジャンプ）評価 |
| [grip_app.html](grip_app.html) | 握力測定・評価 |
| [back_strength_app.html](back_strength_app.html) | 背筋力測定・評価 |
| [grip_back_app.html](grip_back_app.html) | 握力＋背筋力 複合評価 |

## 測定評価シート データ入力アプリ（sheet_input_app.html）

スキャンした測定記録用紙（PDF・画像）を見ながら数値を入力するためのデスクトップ向けアプリ。

### 主な機能

- **PDF/画像の表示**：スキャンした記録シートを左ペインに表示しながら入力
- **OCR自動読み取り**：Tesseract.js を使用してスキャン画像から数値を自動認識
- **名前の一括入力**：Excelからコピペで氏名・学年・性別を一括入力
- **CSV/MD出力**：入力データをCSVまたはMarkdown形式でダウンロード

### 対応種目（6種目）

| 種目 | 測定項目 |
|---|---|
| 30m走 | 10m・20m・30m（2試技） |
| メディシンボール投げ | 3試技（予備含む） |
| CMJ | 跳躍高・滞空時間（2試技） |
| リバウンドジャンプ（RJ） | 跳躍高・RSI（2試技） |
| 握力 | 左右各2試技 |
| 背筋力 | 2試技 |

### 使い方

1. ブラウザで `sheet_input_app.html` を開く
2. 上部メニューで**種目**・**測定日**・**測定者**を設定
3. 「📂 スキャンを開く」でPDFまたは画像を読み込む
4. 「📋 名前を一括入力」でExcelから氏名をペーストするか、直接入力
5. 「🔍 OCRで数値読み取り」で数値を自動認識（結果を確認して適用）
6. 「📥 CSV」または「📄 MD」でデータをエクスポート

### OCR について

- [Tesseract.js v4](https://github.com/naptha/tesseract.js) をCDNから動的読み込み（初回は数秒かかる）
- **英語（数字）のみ**認識。日本語文字は無視されるため数値のみ抽出
- OCR結果はプレビューで確認してから適用可能（緑：正常、黄：要確認）

### 名前一括入力（Excelペースト）

Excelで氏名・学年・性別の列を選択してコピーし、ダイアログに貼り付けると自動的に3列に振り分けられます。

```
山田 太郎	4年	男
鈴木 花子	2年	女
```

## 各評価アプリ（CMJ / 握力 / 背筋力）

いずれも以下の共通機能を持ちます。

- **偏差値・グレード（A〜E）表示**：参照規準値をもとに個人の位置を可視化
- **個票PDF印刷**：ブラウザの印刷機能でそのまま個票を出力
- **CSV出力**：グループ全員のデータをまとめてエクスポート

| アプリ | 特記事項 |
|---|---|
| CMJ | Haugen et al. (2021) の規準値使用。飛行時間からピークパワー算出 |
| 握力 | 左右差インジケーター付き |
| 背筋力 | 体重比（相対値）でも評価 |
| 握力＋背筋力（複合） | 2種目を1画面で同時入力 |

---

## 動作環境

- モダンブラウザ（Chrome / Edge / Firefox / Safari）
- インターネット接続：OCR使用時のみ必要（Tesseract.js のCDN読み込み）
- サーバー不要。HTMLファイルをダブルクリックして直接開いて使用可能
